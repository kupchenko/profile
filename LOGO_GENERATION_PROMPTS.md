## Quick Generation Guide

### Using DALL-E (ChatGPT):
1. Copy the prompt
2. Paste into ChatGPT
3. Download the generated image
4. Save as the specified filename in `/public/projects/`

### Using Midjourney:
1. Use command: `/imagine prompt: [paste prompt here] --ar 1:1 --v 6`
2. Upscale your favorite version
3. Download and save

### Using Stable Diffusion:
1. Use prompt with these settings:
   - Aspect ratio: 1:1
   - Steps: 30-50
   - CFG Scale: 7-9
   - Sampler: DPM++ or Euler A

### Post-Processing (if needed):
- Remove background: https://remove.bg
- Resize to 512x512: Use any image editor
- Optimize for web: Use https://tinypng.com
